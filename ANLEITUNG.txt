VitalKompass 2.0.0 – Reparatur eines automatischen GitHub-Tests

Ausgangslage: Version 1.9.8 bleibt aktiv. Der erste 2.0.0-Versuch hat die neue
App NICHT veröffentlicht. Ein Test-Hilfswert (sortdate) fehlte nur in der
Testumgebung, nicht in der App.

Installation auf iPhone:
1. vitalkompass-200-reparatur.yml aus dem ZIP entpacken.
2. Auf GitHub in VitalKompass das Verzeichnis .github/workflows öffnen.
3. Datei dort hochladen und "Commit changes" bestätigen.
4. EXAKTER Pfad muss lauten:
   .github/workflows/vitalkompass-200-reparatur.yml
5. GitHub Actions startet die Installation und Tests automatisch. Erst wenn
   "Success" erscheint und GitHub Pages erfolgreich veröffentlicht hat,
   ist 2.0.0 installiert.

Wenn GitHub die Datei ins Hauptverzeichnis hochlädt:
Die dortige Datei in GitHub bearbeiten und den Dateinamen in
.github/workflows/vitalkompass-200-reparatur.yml ändern, Commit bestätigen.

Keine Gesundheitsdaten oder Backups bei GitHub hochladen. Die vorhandenen
verschlüsselten Daten und das App-Passwort werden nicht geändert.
